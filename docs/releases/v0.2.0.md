# v0.2.0 — 主 bundle 默认关闭系统自带的 dsh-goal

本版本把「关闭 DSH 自带 `dsh-goal`」的关闭层**内置进主 bundle**：
安装 `@yankeguo/dsh-infini-goal-bundle` 即默认关闭官方 goal 模式，**不再需要额外安装**
`@yankeguo/dsh-disable-goal-bundle`；它贡献的每一行仍可在 Plugins 页面单独开关，关掉整个
bundle 即恢复官方 goal。

## 行为变化（升级前必读）

- **安装/升级主 bundle 后，系统自带的 `dsh-goal` 默认关闭**：不再有官方自动轮次、GoalBar、
  `/goal` 命令与 `get_goal` / `create_goal` / `update_goal` 工具；`goal` 服务仍保留在 host 平面
  （preset 激活需要它），只是变惰性。infini-goal 成为唯一的目标系统。
- **旧 profile 仍选中伴生 bundle 时运行安全**：两个 bundle 故意共用同一批 row id，DSH 组合出
  重复的 insert 行但 Loader 每个 id 只挂载一个 entry（后插入者生效），preset filter 不会重复
  挂载、不会报 `Duplicate agent preset`。但 Plugins 页面将无法单独开关这 3 个 filter 行，
  因此**推荐只保留主 bundle**：在 Plugins 页面取消 `@yankeguo/dsh-disable-goal-bundle`，
  或重跑本地 `pnpm install:profile`（脚本会自动取消选择并清掉 profile patch 里旧的生成块）。
- **`--disable-builtin-goal` 已废弃**：仍被接受但不再产生效果，只打印提示；主 bundle 默认
  就关闭官方 goal。
- 想恢复官方 goal：在 Plugins 页面**关掉整个主 bundle**（而不是重新启用伴生 bundle）。

## 实现

- 主 bundle 的 `dsh.bundle.patch` 改为**有序文件数组**：
  `./cordis.patch.yml`（5 个 infini-goal 行）→ `./cordis.disable-goal.patch.yml`（生成的关闭层：
  停用 `goal-round-driver` / `ui-goal` / `preset-standard` / `preset-ptc` / `preset-cordis`，
  并为每个 shipped preset 挂一个很小的 `preset-filter` 行，启动时读取**已安装**的 preset、
  去掉 `command-goal` / `tool-goal` 后重新挂载——不复制 preset 内容，DSH 升级无需重新生成）。
- 两个生成的 patch（主 bundle 内嵌层与独立 bundle 的 `cordis.patch.yml`）由
  `scripts/build-disable-goal-bundle.mjs` 从**同一个生成器**输出、内容逐字节相同，
  `--check` 同时校验两个文件与 bundle manifest 接线（`pnpm test` 也会执行该校验）。
- 主 bundle 新增运行时依赖 `@yankeguo/dsh-disable-goal-bundle`（filter 行 import 其
  `./preset-filter` 模块）；独立 bundle 仍可单独使用于「只想关闭官方 goal、不装套件」的 profile。
- `scripts/install-profile.mjs`：只选主 bundle、自动迁移旧 profile（取消伴生 bundle 选择、
  清除旧生成 patch 块）；新增 `packages/bundle/tests/composition.spec.ts` 与
  `tools/e2e/probe-bundles.sh` 回归。

## 升级

```sh
# 升级主 bundle（发布后）
dsh plugin --profile desktop add @yankeguo/dsh-infini-goal-bundle@0.2.0

# 本地 checkout
git pull && pnpm install && pnpm build && pnpm install:profile
```

升级后在 Plugins 页面确认主 bundle 已启用；若 profile 仍选中
`@yankeguo/dsh-disable-goal-bundle`，取消它（本地安装脚本会自动处理）。preset 变更只影响
之后创建的 Agent，彻底生效建议重启一次 DSH。
