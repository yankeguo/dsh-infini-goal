# v0.1.0 — dsh-infini-goal 首个发布

参考官方 `dsh-goal` 的领域模型、模型工具与 UI 形态，把"自动续跑"改造成
**无轮次上限、按最小间隔推进、可配置静默时段**的无限目标。

## 亮点

- **无轮次上限**：目标保持 `active`，直到被暂停 / 阻塞 / 完成 / 清除；
- **最小触发间隔**：两次自动轮次开始时间至少相隔 `minIntervalMs`（默认 60s，最小 1s），
  空循环不会秒回秒触发；
- **静默时段**：可配置本地时间段（支持跨午夜、按星期过滤、IANA 时区），
  时段内不自动触发；人类对话、工具调用照常工作，时段结束后自动继续；
- **事件溯源**：所有变更写入 Session 日志（`infini-goal/change`），严格回放校验，可跨重启/恢复/fork；
- **模型工具**：`get_infini_goal` / `create_infini_goal` / `update_infini_goal`；
- **人类命令**：`/infini-goal`（状态、创建/编辑、暂停/恢复/完成/阻塞/清除、interval/quiet/timezone）；
- **状态条 UI**：composer 上方显示阶段、轮次、触发节奏、静默时段状态与生命周期按钮。

## 兼容性

- DeepSeek Harness：`>=0.2.2-rc.1 <0.3.0`（`engines.dsh`）
- Node.js：`>=24.9`（构建与发布工具链）

## 安装

```sh
dsh plugin --profile desktop add @yankeguo/dsh-infini-goal-bundle@0.1.0
```

或在 Web 的 **Plugins → Add plugin** 中输入 `@yankeguo/dsh-infini-goal-bundle`。

本地 checkout 开发模式：

```sh
pnpm install && pnpm build
pnpm install:profile
```

## 已知限制

- 每个 Session 同时只有一个 infini-goal；
- `active` 是持久化状态：DSH 重启、会话恢复、fork 后会继续（不需要时先 `pause`）；
- 静默时段的配置若覆盖全天会被拒绝；
- DSH 升级到 0.3 前需要更新 `engines.dsh` 并做一次回归。
